# raippaluoto.fi

A guide to the island of Raippaluoto in Mustasaari. English is at `/`. The old address `/en` redirects to the homepage.

Maps are Huts.fi embeds: a category map on each guide, and a place or route map on each individual page.

The site deploys from `main` on the Vercel project for raippaluoto.fi. It is not part of huts.fi.
